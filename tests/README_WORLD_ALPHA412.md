# RPG Dynamic World — Alpha 4.1.2

- `/shop` учитывает объявленное количество на прилавке, ответ на вопрос о цене и ценник на дощечке с остатком товара в следующей фразе. Повторный запрос цены сохраняет уже подтверждённый запас.
- Статусы «скрылся в лесу» и «ушёл в чащу» исключают существо из целей боя. Укрытие внутри сцены сохраняет доступность цели. Явно описанный уход гоблина между стволами записывается в энциклопедию.
- Именной участник сцены, который явно ведёт повозку, попадает в энциклопедию, даже если мастер пропустил отдельную запись о нём.

Распакуйте ZIP в корень репозитория. После развёртывания `/api/health` вернёт `2026-11-27.world-alpha4.1.2`.

Для локальной проверки установите зависимости из `requirements.txt` и выполните `python -m unittest discover -s tests -v`.
