# RPG Dynamic World — Alpha 4.1.3

- Лавка сохраняет количество, когда мастер говорит «на прилавке остаются оба пайка» или называет цену за штуку после описания ассортимента.
- Остаток в соседней фразе сверяется с товаром. Запас другого товара не меняет выбранное предложение.

Распакуйте ZIP в корень репозитория. После развёртывания `/api/health` вернёт `2026-11-27.world-alpha4.1.3`.
