# RPG Dynamic World — Alpha 5.1.2

Игровой прогон на Alpha 5.1.1 прошёл в новой истории «Последний звон Стеклянной гряды».

- Механик с именем появляется в энциклопедии при представлении. Одноимённые страж и торговец сохраняют свои ID.
- Лавка связывает озвученные цены с количеством каждого показанного товара. В проверенной сцене один разводной ключ стоил 8 серебряных, а три штифта — по 2 серебряных за штуку.
- Явно переданный герою предмет, который тот попросил одолжить, сохраняется в инвентаре. Просьба или условное предложение без передачи предмет не добавляет.
- Явная просьба проверить навык с указанными DC и модификатором создаёт карточку даже без команды /roll в реплике.
- Выстрелы по учебным мишеням получают карточку, даже если мишень записана как предмет и мастер не указал её защиту. Для такой мишени базовая КБ 10. Три четверти укрытия добавляют 5 к защите. Подтверждённый бросок расходует одну стрелу при попадании и промахе.
- Установленный штифт расходуется при явном результате, включая успешное завершение ожидающего броска. Повтор прежнего хода или пересказ результата не расходует ещё один штифт.

После установки поле app_revision в /api/health покажет 2026-11-27.world-alpha5.1.2.
