# RPG Dynamic World — Alpha 4.1.1

- Явно описанный побег гоблина из засады сохраняет статус «сбежал» для однозначно определяемой цели. HP и запись в энциклопедии сохраняются. Сбежавшего противника нельзя атаковать в прежней сцене.
- Текстовый выстрел с объявленной проверкой списывает боеприпас и тогда, когда мишень ещё не записана в энциклопедию.
- Лавка учитывает фразы «Осталось два» и «есть два дорожных пайка по 3 серебряных». Начальное количество в названии товара больше не мешает найти предложение. Сумма покупки и запас сверяются с сохранёнными данными.
- Покупка обычным текстом учитывает подтверждение оплаты или передачи товара рядом с названной ценой. Отказ, условное предложение и повторная публикация хода не списывают деньги.
- Заклинания с механикой маны или перезарядки, которые можно применить командой `/cast`, отображаются в активных умениях.

Распакуйте ZIP в корень репозитория. После развёртывания `/api/health` вернёт `2026-11-27.world-alpha4.1.1`. Для текущих партий миграция сохранений не требуется.

Локальная проверка после установки зависимостей выполняется командой `python -m unittest discover -s tests -v`.
