# RPG Dynamic World — Alpha 5.1.3

- Подтверждённое совместное прибытие сохраняет новое место NPC с прежним ID. Если герой уходит один, NPC остаётся в последней подтверждённой локации.
- Когда незнакомец в другой локации представляется именем знакомого NPC, неподтверждённое заявление не переносит существующую запись и не создаёт вторую подтверждённую личность. Явно представленные одноимённые NPC продолжают получать отдельные ID.
- Подтверждённое воссоединение остаётся доступным мастеру после длинной главы с другими персонажами и событиями.
- Сохранения импортируются с прежними репликами и состоянием. Исправление применяется к следующим ходам и не переписывает сыгранную историю.
